# Tourism Tajikistan Web Application

## About Project

Tourism Tajikistan is a web application developed for promoting the cultural and tourism potential of the Republic of Tajikistan.

The platform provides information about:
- tourist routes;
- cultural and historical places;
- attractions of Tajikistan;
- interactive maps;
- tourism infrastructure.

The application supports multilingual interface and adaptive design for different devices.

---

## Technologies Used

### Frontend
- React.js
- TypeScript
- TailwindCSS
- Framer Motion

### Backend
- Django 5
- Django REST Framework

### Database
- PostgreSQL

### Additional Tools
- Leaflet.js
- i18next
- Vercel

## Features

- Interactive tourist map
